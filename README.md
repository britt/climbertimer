# Climber Timer

A SwiftUI interval timer app designed for rock climbers. Built for iPhone and Apple Watch with iCloud sync for presets.

## Features

- **Customizable Intervals**: Set work duration, rest duration, and repetitions
- **Preset Management**: Save and reuse your favorite timer configurations
- **Quick Start**: Default timer ready to go, or pick up where you left off
- **Audio & Haptic Feedback**: Configurable sound, visual, and vibration alerts
- **Apple Watch Support**: Full-featured companion app with iCloud sync
- **Landscape Mode**: Timer views support both portrait and landscape orientation

## Requirements

- iOS 17.0+
- watchOS 10.0+
- Xcode 15.0+
- Swift 5.9+

## Installation

1. Clone the repository
2. Open `ClimberTimer.xcodeproj` in Xcode
3. Build and run on your device or simulator

## Usage

1. **New Timer**: Tap "New Timer" to create a custom interval timer
2. **Presets**: Save your configurations for quick access later
3. **Quick Start**: The last used timer is always available on the home screen
4. **Settings**: Configure audio, visual, and haptic feedback preferences
